# Examine

Paste a prediction market link (Polymarket, Kalshi, PredictIt, Manifold) or
upload a screenshot, and get an AI-generated fair-odds estimate, edge vs. the
current market price, confidence, key factors, sentiment read, and historical
comparisons — with EV and Kelly-sized bet recommendations.

## Stack

- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS
- **Backend**: FastAPI, SQLAlchemy (async), Redis (cache), Anthropic Claude
- **DB**: SQLite for local dev by default; Postgres via `docker-compose.yml` or Supabase in production
- **OCR**: Local Tesseract (`pytesseract`) — no API key required
- **Market data**: Live public APIs for Polymarket (Gamma API), Manifold, and PredictIt; best-effort HTML scrape fallback for Kalshi and anything else

## What's real vs. stubbed

- ✅ **Live**: Polymarket / Manifold / PredictIt market data fetching, platform URL detection, Claude-powered analysis (structured tool-use call), EV/Kelly/edge math, OCR via Tesseract, Redis caching (falls back to a no-op if Redis isn't running).
- ⚠️ **Best-effort**: Kalshi (no public unauthenticated API for most markets — falls back to HTML scraping), sentiment/historical comparisons (currently generated by the Claude call from its own knowledge rather than a separate news API — wire in `NEWS_API_KEY` and a fetcher in `app/services/` to make it live).
- ⏭️ **Deferred** (per scope decision): browser extension, tiered/paid access limits. Core analysis flow was prioritized first.

## Setup

### Backend

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

Copy `.env.example` to `.env`... but `.env` already exists locally with your
Claude key filled in (kept out of git via `.gitignore`). Fill in the rest as
you get them — see **Credentials** below.

```bash
uvicorn app.main:app --reload --port 8000
```

Backend runs at `http://localhost:8000`. Health check: `GET /api/health`.

By default `DATABASE_URL` points at a local SQLite file (`backend/examine.db`)
so you can run without Docker. To use real Postgres:

```bash
docker compose up -d postgres redis
```

then set `DATABASE_URL=postgresql+asyncpg://examine:examine@localhost:5432/examine`
in `backend/.env`.

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs at `http://localhost:3000` and calls the backend via
`NEXT_PUBLIC_API_URL` (see `frontend/.env.local`, defaults to
`http://localhost:8000`).

Treat it as compromised — rotate it (revoke + generate a new one) in the

The key that's configured also currently has **no credit balance** — Claude

| Service | Required for | Status |
|---|---|---|
| `ANTHROPIC_API_KEY` | AI probability analysis | configured, needs credits |
| `OPENAI_API_KEY` | Alternate AI provider (optional, unused unless you wire it into `ai_engine.py`) | not set |
| `GOOGLE_VISION_API_KEY` | Higher-accuracy OCR (optional — Tesseract works without it) | not set |
| `DATABASE_URL` / Supabase | Persistent Postgres in production | local SQLite for now |
| `REDIS_URL` / Upstash | Market-data caching | optional, degrades gracefully |
| R2 vars | Screenshot storage in production | not set — uploads aren't persisted to disk today, only OCR'd in-memory |

## API

- `POST /api/analyze/url` — `{ "url": "..." }` → full analysis
- `POST /api/analyze/image` — multipart `file` upload → full analysis
- `GET /api/analyses/{id}` — fetch a saved analysis
- `GET /api/analyses` — list recent analyses
- `POST /api/analyses/{id}/resolve` — `{ "actual_outcome": true|false }`, records the real outcome for Brier-score calibration tracking
- `GET /api/calibration` — overall Brier score + accuracy buckets across resolved analyses
